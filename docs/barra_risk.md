# S6 Barra风格风险研究

本模块自行实现多因子风险模型，不使用MSCI商业Barra数据，也不声称复刻CNE5。
它独立读取冻结数据和S6账户，输出风险暴露、因子收益、特异收益、协方差、风险贡献和复利衔接归因，不训练选股模型、不导入券商SDK、不改变交易计划。

## 运行

在完整研究环境、具有本地冻结数据与S6五个账户的前提下：

```powershell
python -m paper_futu.research_barra --stage all
```

阶段为`audit/data/factors/risk/report/all`。默认目录为
`reports/experiments/barra_s6_v1_asof_20261013`。使用独立`--output`可以启动不同的数据配置，输出必须位于本项目实验目录内。已完成阶段复用经过哈希验证的产物；代码或源数据变化会拒绝沿用原协议，需另建输出目录。

当前历史截止2026-10-13，并非实时风险。S6账户为季度QREG、Top20、前6只40%、5日调仓、最多换6只，五个预设起点分别计算。

## 风格定义

所有描述符在t日收盘可知，使用t日暴露解释t+1日收益。它们是研究代理，不是商业Barra的原始描述符。

| 风格 | 本实现 |
|---|---|
| Beta | 252交易日股票收益对动态股票池等权市场收益的滚动OLS Beta，至少126日 |
| 动量 | 跳过最近20交易日的此前126日累计对数收益，至少100个观测 |
| 残余波动 | 股票收益减滚动Beta乘市场收益，残差最近60日标准差，至少40日 |
| 账面估值 | 最新已披露每股净资产/未复权价格 |
| 盈利收益率 | 最新已披露完整年度EPS/未复权价格，非TTM |
| 流动性代理 | 负对数的20日平均“绝对收益/近似成交额”；近似成交额=复权收盘价×已归一化成交量×100，至少15日；更高表示更流动 |
| 现金流质量 | 最近已披露经营现金流/营业收入 |
| 成长 | 最近已披露营收同比增长率 |
| 杠杆 | 最近已披露资产负债率 |
| 盈利能力 | 最近已披露ROE，沿用原始报告期间口径 |

MAD去极值后横截面标准化；缺失字段中性填充前记录覆盖率。含缺失描述符的股票特异方差提高50%，这是明确的保守研究假设，不是校准得到的系数。常数描述符记零并标记，回归不拟合其无法识别的收益。

本地没有可核验历史行业、市值时，行业只有`UNCLASSIFIED`，不使用当前分类回填历史，规模与非线性规模不运行。报告明确为覆盖不完整的市场与风格风险模型，不能作为完整行业、规模调整后的Alpha证明。

## 历史行业与市值导入

```powershell
python -m paper_futu.research_barra --stage all --industry-events data/external/industry_pit.parquet --capital-events data/external/capital_pit.parquet --require-full --output reports/experiments/barra_s6_full_v1
```

行业Parquet字段：`instrument, industry, effective_date, available_date, source_url`。
市值Parquet字段：`instrument, market_cap, effective_date, available_date, source_url`。
日期可解析，证券代码与本项目一致，`source_url`为HTTPS原始来源，市值为正。
可用日期是生效日期和可得日期的较晚者，只向后匹配；当前快照须使用真实取得日期，不能把历史生效日期当作历史可得证明。
市值为每日观测，超过7个自然日不沿用。导入市值后增加对数规模和对规模正交的三次非线性规模。

`--require-full`要求历史行业、市值覆盖均至少98%；否则拒绝完成完整模式。未提供此参数时仍将缺口公开记录在`data_profile.json`。原始资料的历史正确性仍需核验，字段格式检验不等于已认证来源。

## 回归与预测风险

股票日超额收益=`country + industry + style + specific`，无风险利率有效年利率1%，按252日折算。
动态估计池为当时沪深300成员，解释收益前暴露滞后一交易日。采用受约束最小二乘，行业因子收益按池权重加权和为零，消除与市场截距的共线性。有完整当日市值时回归损失权重为市值平方根，否则整日用等权，避免部分股票被隐式删除。

共同因子协方差使用过去252日，半衰期63日，向对角矩阵收缩20%，数值特征值设正下限。
特异方差使用过去126日残差，半衰期42日，至少60日，50%向当时横截面中位数收缩；短历史回退到中位数的两倍。缺失残差不填零。

账户日方差=`b' F b + Σ(w_i² d_i)`，`b=w' X`。Euler贡献可为负，因共同因子之间存在协方差；因子贡献和个股特异贡献之和须等于总方差。
风险使用截至t日收盘的信息预测t+1；校准比较冻结t日收盘持仓在t+1实际个股收益下的表现，避免混入次日调仓。持仓模型覆盖不足98%则拒绝给风险数值，列出失败原因。

未建历史沪深300权重数据，因此暂不提供声称相对该指数的主动因子暴露和预测跟踪误差。等权估计池不是指数权重。

## 已实现收益归因

前一日持仓对应的市场、行业、风格和个股残差收益，与实际开盘换仓产生差异。差异单列为`execution_timing`，交易费用单列，股票投资部分的无风险基准单列，现金不虚构利息。
逐日各项严格合计为真实账户净收益；贡献乘此前账户净值后累加，复利衔接到期末累计收益。五起点先各自计算再取均值，不能当成五个独立样本。
残差和交易时点桶不称为纯Alpha。遗漏行业、规模、个股残差相关性、财务修订档案不完整均可能影响结果。

## 主要输出

- `protocol.json`：数据、模型、代码和账户来源哈希。
- `data_profile.json`、`descriptor_coverage.csv`：行业、市值、风格覆盖与缺失。
- `factor_returns.parquet`、`specific_returns.parquet`：每日估计收益。
- `latest_asset_exposures.parquet`、`latest_factor_covariance_daily.csv`、`latest_specific_risk.csv`：最新风险计算组件。
- `risk_forecasts.csv`、`latest_factor_risk.csv`、`latest_stock_specific_risk.csv`：风险、覆盖、贡献。
- `return_attribution.csv`与逐日起点文件：已实现收益归因及对账。
- `report.html`、`risk_overview.png`、`summary.json`、`completion.json`：报告与验收。

所有收益仍来自反复参与研究的2022—2026区间，风险校准也不是新的独立测试。不按风险报告自动切换组合或下单。

方法背景：[MSCI Barra China Equity Model](https://www.msci.com/documents/10199/2935796a-0a80-4050-934a-12966d1e2518)。实现参数为本项目透明研究选择，无商业模型等价承诺。

## 历史行业与规模补齐研究

新增`paper_futu.fetch_barra_metadata`，缓存799只历史股票的巨潮行业分类变更和东方财富股本变动记录。来源响应、请求参数、取得时间及哈希均保留。股本采用已上市流通A股与限售A股之和；不把H/B股按A股价格估值。股本在“变动生效日”和“公告日后一天”均达到后才能使用，再乘该日未复权A股收盘价计算日市值。

行业使用巨潮历史申万分类变更，而非今天的行业快照；2014和2021分类设置研究使用下限。源数据不包含完整首次发布时间档案，因此行业日期仍是研究假设，主研究延迟93个自然日，另做1日延迟敏感性。退市/合并股票缺失保留为未知。不能把这一版本称为无修订的严格历史PIT数据库。

```powershell
python -m paper_futu.fetch_barra_metadata --stage all --workers 4
python -m paper_futu.research_barra_full --stage all
python -m scripts.report_barra_full_findings
```

新增目录`reports/experiments/barra_s6_industry_size_asof_20261013`，旧v1报告不变。主研究、等权公平对照和行业日期敏感性分别绑定代码、数据及原账户。各因子包括市场、行业、原10项风格、规模及非线性规模；非线性规模为标准化对数市值的三次项，去极值在正交化前完成，按该模型权重对截距和规模正交后仅重标度。

“净残差”定义为账户净收益扣除模型共同因子贡献和股票无风险基准部分，包含个股残差、开盘交易时点差异及原策略实际费用。日均值乘252为年化算术均值；按原账户净值衔接得到累计贡献。两者均不等于可实际实施的对冲策略复合收益，不包含另建对冲组合的费用。

HAC区间逐起点计算（20阶主值、60阶敏感性），不能把五个高度相关起点合并成独立样本，也不能校正已经发生的历史参数搜索。主研究的历史行业和市值覆盖率分别约98.71%、99.95%；没有取得历史沪深300权重，仍不提供伪造的指数主动风险。
