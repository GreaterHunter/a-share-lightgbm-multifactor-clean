# S6冻结规则与前瞻模拟

历史研究的主评价基准固定为沪深300全收益指数H00300；000300价格指数保留对照。历史选优到此停止，前瞻记录只使用冻结后、既定执行日起产生的新观察，不回填2022—2026为独立测试。

[全收益基准及风格归因](../reports/current_strategy/total_return/README.md)保留了官方来源、响应哈希、日期核对、逐年与五起点结果。原始指数日线只在本地保存，不随公开仓库分发。

## 固定规则

- S6季度从零拟合，原始15因子，未来10日开盘至开盘收益排名为目标。
- 从2010年扩展使用成熟标签；每年用此前三年验证折选树数，年内固定。季度更新模型不等于重新搜索参数。
- L1=1、L2=5、15叶、叶子最小样本300、种子42、四线程。
- Top20，前6只合计占股票仓位40%，目标股票仓位95%；每5个交易日调仓，最多替换6只。保留仓位仍只交易差额。
- 使用现有已授权的模拟盘切换日期及09:31后限价执行，不临时提前调仓，也不自动启动另一条交易策略。
- 当前季度包到期后必须提供同规则下验证合格的新模型；缺包应停止服务。没有自动季度训练任务。
- 财务事件快照按模型包哈希锁定；未经核验的财务刷新不能混入本版前瞻验证。若要更换，先登记新版本及其生效时间。

## 冻结与观察分离

`paper_futu.prospective_s6`不导入富途SDK、不连接券商、不下单、不撤单、不改持仓或交易调度。它只读取本机已有计划、收盘资产和订单回执，下载公开指数，用独立目录记录结果。

冻结必须先完成全收益归因，并在下一次信号日之前登记；不能在看过执行结果之后补登记。协议记录模型、元数据、财务、执行代码、配置规则及归因报告哈希。协议和每日记录采用独占写入，代码或模型变化会阻止继续记为同一版本。

本机完整路径、账户资产、持仓和真实交易日期只在被Git忽略的本地协议及记录中保存，不复制到公开参数配置。

```powershell
python -m paper_futu.prospective_s6 --stage freeze --attribution reports/current_strategy/total_return/manifest.json
python -m paper_futu.prospective_s6 --stage status
python -m paper_futu.prospective_s6 --stage record
```

这些命令需要已配置的本机模拟环境，不是新克隆后的即用交易入口。公开副本没有账户配置和模型包，不能据此发单。

## 日期和账户边界

沿用现有账户，而不是假设重新得到100万元现金。基线为首次执行日前一个信号日的真实收盘资产，首次执行日仍可能包含旧持仓的隔夜收益，单独标记为过渡。不会将历史理想开盘账户净值拼接到模拟盘。

每个交易日必须有当天15:35后的资产记录。缺失前一交易日、官方指数或模型/计划不匹配时，停止计算，不补零、不插值。H00300用前收盘至当日收盘，与账户收盘记录对齐。市场Beta及Alpha是归因统计，不是自动对冲交易。

本版本约定不出入金、不人工干预持仓；出现外部资金流或人工交易，应暂停本版绩效解释并登记，不能当作策略盈利。资产记录本身不能独立证明没有外部资金流。

## 成交与费用

资产净值直接使用模拟账户观察值，不重复扣费。另按实际成交金额估计买入0.05%、卖出0.15%、每笔最低5元的模型费用。模拟盘是否已扣全部真实佣金、税费尚未独立核验，故估计费用不冒充真实费用，未核验前不声称得到真实成本后收益。

订单回执与执行完成记录保留本地，未成交、部分成交与现金未充分投入不能静默抹掉。09:31限价成交不等于回测的理想开盘成交。

## 日终任务和复核

只读观察任务每日17:45启动一次，周末或非交易日直接退出，不需Codex在线。它不替代原有09:20交易工作进程。交易工作进程仍需电脑唤醒联网、Windows用户登录及OpenD登录在线；观察器只读取已经保存的结果。

```powershell
powershell -File scripts/install_s6_observer_schedule.ps1 -Python <模型环境的pythonw.exe绝对路径>
```

20个交易日先复核执行完整性和摩擦；63及126日再复核收益、全收益超额、回撤及行业依赖，不因短期排名改参数。30%回撤是人工复核告警，不是观察器自动清仓授权。任何规则更改另开前瞻版本，不覆盖旧记录。
