## 检查方式

初始提交使用只读工具扫描本仓库的所有可达引用，并复查文本、二进制清单和私有文件路径。研究图表为历史收益、净值与回撤，不包含账户截图。提交邮箱采用GitHub noreply地址。

```powershell
python -m scripts.audit_public_history --summary
python -m examples.offline_demo
python -m pytest -q
```

工具检查私钥、若干常见令牌、带凭据URL、字面量密码和API密钥、完整账户标识、个人目录及工作目录模式，输出匹配类别和位置，不打印候选凭据。模式检查不能证明绝无敏感信息，也不覆盖外部克隆、缓存、原开发仓库或所有二进制内容。

研究参数与统计口径保持原样。财务覆盖报告是标有说明的派生公开副本，源路径使用仓库相对路径；统计与源内容哈希保留，见[财务覆盖证据](evidence/financial_coverage.json)。研究结果的样本选择、历史反复试验和成交假设局限见[研究结果](results.md)。

历史实验的源码哈希按原始字节计算，包含换行。`.gitattributes` 对这10个已绑定源码保留原始字节，避免克隆时换行转换破坏原科学协议；没有更改历史预期哈希或绕过校验。

初始展示快照验证结果为269项测试通过、2项依赖本地私有数据的检查跳过；合成数据示例运行成功。受检文本未命中工具列出的敏感信息模式。

后续当前策略报告附有五个起点的每日研究汇总、逐起点指标和绘图脚本，均为已审计离线回放的派生结果。导出字段限定为日期、起点偏移、净收益、基准收益、净值、费用、换手及持仓数量；没有导出券商标识、订单、逐股票持仓、本机路径或模型包。来源哈希保留在[报告证据](../reports/current_strategy/evidence.json)。
