# 数据契约与复现边界

## 已公开和未公开内容

| 内容 | 仓库包含 | 作用 |
|---|---|---|
| 代码、测试、公开研究参数 | 是 | 检查研究与执行逻辑，不包含本机部署登记 |
| 选定CSV/HTML研究汇总 | 是 | 阅读历史结论，核对公开指标 |
| 原始行情与财务数据 | 否 | 受数据来源和再分发条件约束 |
| 冻结面板、模型、完整账户与任务缓存 | 否 | 完整复算所必需，本地保存 |
| 模拟账户配置、订单、交易凭据 | 否 | 仅用于已授权的本机模拟盘 |

发布汇总不等于发布全部可复算数据。完整研究依赖父实验产物，当前尚未将数据获取到全部实验恢复封装成可移植的一键流程。

## 时间与索引

- 股票日期索引唯一，常用MultiIndex为 `instrument, datetime`。
- 窗口按交易所交易日计算，不按自然日，不按任意删除的股票行计算。
- 开盘标签为 `Open[T+H+1]/Open[T+1]-1`。H=10时，最后一笔收益的结束日期在信号后第11个交易日。
- 每次拟合、每个验证折分别要求 `label_end_date <= 截止日`，未来标签未知的行不训练，但可保留特征用于预测。
- 不以已观察k日收益除以k替代完整H日标签，不随机混合训练与验证日期。

当前S6使用原始因子，目标才做每日横截面平均秩百分位减0.5；不能把“排名目标”误写成“所有输入也排名”。

## 股票池与数据单位

使用Qlib提供的历史CSI300成分区间，不用今天的名单直接回填。成分生效日和数据版本仍需审计；“动态股票池”不是已经彻底排除生存者偏差的证明。

历史Qlib复权价格、复权因子与本地最新行情必须处于相同尺度。项目历史曾发现成交量单位不一致并暂停相关补仓，不能忽略单位审计。Qlib来源成交量按手和复权因子缩放、成交额按千元；富途日线按股、元；转换约定以对应数据适配器和快照为准，不可通用于任意供应商。

## 财务可用时点

财务值按可核验实际披露日期对齐，不能按报告期结束日期提前使用。现有保守规则从披露日后开始可用；修订前历史值的完整档案仍不足，因此不是无缺陷的机构级PIT数据库。

截至固定2026-10-13快照，末日300只股票中290只对齐2026半年报，10只一般财务对齐缺失；B/P、E/P各缺11只，现金流/收入缺10只。E/P使用最近已披露完整年度基本EPS（覆盖股票主要为2025年），不是季度EPS或TTM。未纳入2026三季报。

估值分母使用未复权价格匹配每股财务口径；收益与价量研究使用一致的复权序列。复权价格不能自动解决所有整手、分红现金到账和交易执行问题。

## 准备完整实验前的检查

1. 确认数据使用和再分发授权，保留供应商、获取日期和版本。
2. 检查交易日连续性、股票日期重复、无穷值、缺失率与上市/停牌情况。
3. 核对复权尺度、量额单位及财务披露生效日。
4. 保存数据快照和哈希，准备协议引用的父实验预测及账户。
5. 验证边界不越界、模型保存重载一致、净值与费用可复算。

公开仓库不提供私有文件的自动下载链接。缺少冻结文件时只能重建并登记为新实验，不能声称已原样复现历史数字。
