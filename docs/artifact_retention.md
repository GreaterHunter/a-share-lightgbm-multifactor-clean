# 研究产物保留与清理

公开reports只放汇总、图表、脱敏证据及必要聚合序列。当前部署、交易记录和原始数据只留本地。

## 保留

- 当前模型、协议、计划、回执、公司行动证据，保持原路径。
- 冻结数据、预测、模型、权威任务JSON、账户明细及科学哈希，用于复现。
- 有结论价值的成功和失败实验，不按收益好坏选择性删除。
- 历史报告与引用路径，不为整理覆盖预期哈希。

## 清理

已完成实验的MLflow目录反复存储相同code_diff、状态及标签。权威记录在tasks、模型、预测、accounts中独立保存，原交付脚本也将mlruns列为可变跟踪内部文件。

本轮只针对两个旧大型实验的mlruns：压缩到项目外本地归档，逐成员SHA-256核验后删除reports中的散文件。科学输入输出不迁移、不改哈希，不训练、不切换交易。归档恢复前确认无活动实验，再核验压缩包与成员哈希，恢复到原mlruns路径。归档和机器路径不上传。

不能为减少目录数量直接删除父实验、原始分钟数据或账户明细。未来若舍弃完整复现，应另行明确登记，不能继续声称完整可复算。
