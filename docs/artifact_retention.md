# 研究产物保留与清理

2026-10-30按用户要求进一步精简：59个本地历史实验原目录已永久删除，仅保留300张结果表、主要图表、方法与结论摘要。旧分钟行情副本、特征、预测、逐笔账户、任务缓存及上一轮两个MLflow压缩包不再保留；原有哈希只用于识别当时来源，不代表原件仍可取得。历史结果不再支持完整逐笔复算或原缓存接续，重新研究须重建数据与产物。当前部署模型、运行数据、活动V10协议、交易状态及源码保留。

## 当前保留

- 当前交易依赖：部署模型、日线与财务源、公司行动证据、协议、计划及回执；保持原路径与哈希。
- 项目代码、离线测试、公开精选结果和图表。
- 历史研究摘要：结果与逐年比较、参数和方法说明、主要图表、原始结果来源哈希，以及未完成实验的状态。不会因收益差而删除其结论。

## 明确放弃

历史实验目录中的原始行情副本、特征、预测、逐笔账户、临时进程记录及中间文件。大体积压缩备份也删除。这意味着历史研究结果是留存摘要，不能继续声称全部原件可核查、逐笔账本可重算或缓存能直接接续。重新运行研究需要重建父实验，且公开展示仓库仍不分发行情或活动账户配置。

当前运行必需的财务与行情在data目录，模型在models目录；本轮未清理这些目录。后续模型服务季度仍受原校验约束，不会因清理自动重新训练或跳过校验。
