# 沪深模拟交易：V5执行规则

这是交易执行修订，不是新模型或新的独立测试。S6季度QREG、10日开盘至开盘标签、Top20、前6名占股票仓位40%、每5日调仓、最多替换6只均不变。旧封存报告仍采用旧整手及成交口径。

## 目标与现金分开取整

执行开始时一次冻结净值、名单、参考价及目标股数。目标选上下相邻合法数量中较接近权重的一项，同等误差优先保留原持仓；个股最多比目标多0.5个百分点。组合目标不超过起始净值95%，扣除费用后留5%现金及10元缓冲。现金可负担数量始终向下取整。

组合预算不足时，按每释放一元资金造成的目标偏差增量从小到大减少数量，同等代价先减新仓、再减低排名。不可卖的继承持仓优先遵守可卖数量和T+1，预算无解则停止新增买入。目标股数不因后续重挂或恢复重新计算。因价格变化只能缩减剩余买入，不能因此生成相反方向订单。

## 有界执行

正常窗口09:31—09:51，最后30秒不发新单。每只股票最多3次提交，每次等待20秒；先对手报价，后两次增加1、2个最小价位让价；没有盘口时使用最新价让价0.1%、0.2%、0.3%。任何价格都不得越过初始参考价0.5%的不利边界。保留9.5%保守方向过滤和既有板块价格边界简化，ST及未知交易单位不新买，不能宣称覆盖全部特殊市场规则。

先卖后买，先确认卖出结果与真实资金。实际持仓和预留新股名额最多20只。当前实现每次只保留一笔活动订单，比最多5笔的上限更保守。

撤单申请不是撤单完成。只有确认原单终态和最终累计成交量后才可续单；部分成交只补合法的剩余数量。到期清理最多2分钟，不自动隔日补单。未知下单结果用唯一备注匹配订单，无法唯一确认就停止，不盲目重试。

所有执行入口共用账户锁。持仓、资金、订单强制刷新各8次/30秒；下单12次/30秒；撤单16次/30秒。持仓缓存10秒。其他客户端仍可能消耗OpenD配额，明确查询限频只允许一次退避重试。

## 命令与记录

`python -m paper_futu.execute_cn_plan` 仅预览；加 `--submit` 才执行。`--resume --submit` 明确恢复V5冻结批次；过期后只能核对、撤销本批旧单，不发新单。旧版本不完整批次不会被自动解释成新目标。

本次单独纠偏只授权2026-10-20的 `SZ.300308` 总持股数100：

```text
python -m paper_futu.correct_cn_position --execution-date 2026-10-20 --code SZ.300308 --target-qty 100
```

加 `--submit` 才提交；已有记录需显式 `--resume`；目标是总股数，不是每运行一次再买100股。新窗口实际启动起最多20分钟、最迟14:55结束，不延长旧13:20窗口，不修改已完成调仓标记。已经持有100股时不再买入。

冻结目标、追加式意图日志、券商订单号和成交CSV分别保存；结果区分完成、约束下部分完成、待核对。补仓回执独立于旧调仓CSV，费用观察器合并计算但不重写原始订单。

使用新版本协议记录代码哈希及旧源码归档。缺失的历史起始净值不能补造，V5不解除前瞻归因的原有缺失基线限制。券商模拟净值不重复扣估算费用；佣金假设单列，模拟成交不能证明实盘同样成交。
