# 项目已有成果（2026-10-30）

## 数据与模型

- 动态沪深300股票池、交易日历、量额单位与复权核验；15因子涵盖价量、账面估值、盈利收益率和现金流质量。
- 财务按可核验披露日期后向对齐；估值使用未复权价格，收益使用一致复权序列。修订前财报档案仍不完整。
- 开盘到开盘标签记录真实label_end_date；每折训练、验证和季度重训只用成熟样本，最新特征仍可预测。
- 年度选树与季度拟合分开；完成扩展及3／5／10年窗口、近期加权、L1／L2、复杂度与种子对照。
- 数据、配置、代码、模型与任务哈希可追溯，模型重载和边界检查保留。

## 研究与账户回测

- 账户按日期执行，跟踪现金、整手、T+1、费用、漂移、部分成交、退出与冷却；标签收益不冒充账户收益。
- 1,551个既有完整15因子模型×持仓配置，各5起点，共7,755条账户路径。混合持仓排名不能当公平模型能力排名。
- S2／S4／S5／S6风险诊断：两条模型线各9设置，30预测流、340账户及96区块对照，含逐年IC、风格、种子与摩擦。
- 比较重训频率、Top5／10／20、权重、排名缓冲、直接与分段止盈止损、冷却、预测期限及真实持有期；经典动量作参照。
- 历史Top20 S6季度约束五起点平均年化18.85%、最差回撤30.35%（2022—2026-10-13、原费用），并非当前V10收益。
- 当前80／1、直接10／5的2021—2025连续回放年化16.42%、回撤31.95%；2026另起账户测试，不能无说明拼接。

## 风险与Alpha

- H00300全收益基准纳入分红；无风险年利率1%，保留价格指数对照、Beta、夏普、IR和几何超额口径。
- 自建Barra风格风险模型：滞后暴露、约束回归、因子协方差、特异风险、风险贡献与组合约束，不声称复制商业Barra。
- 历史行业和市值覆盖约98.71%、99.95%；行业可得日期有假设并做敏感性检验。
- 净残差年化算术均值约1.77%，较不完整参照减少76.7%，主区间包含0。残差含个股、时点与费用，不是对冲组合复合收益；尚未证明独立Alpha。
- 组合风险约束可降低集中和预测波动，也可能降低收益；不是自动提升Alpha的工具。

## 分钟因子负面发现

核验657只历史股票及510300分钟代理；训练2015年起，回放2022—2025。6输入组、64次新季度拟合、32个模型复用、28账户及36差异区间均完成审计。

日频／完整分钟净年化9.56%／8.75%，完整交易966／1,225次，费用18.69／23.42万元；每边额外10bp后5.50%／3.05%。IC增量区间均跨0，未确认稳定增益。时段组虽收益较高，但16个季度均未用时段列分裂，不能将变化归因于时段信息。未据此切换主策略。

## 模拟执行工程

- 日线更新不依赖OpenD在线；开机补齐已完成交易日，数据未就绪不下单。
- 全组合冻结目标股数；目标取整与可负担股数分开，避免高价入选股被整手取整误清仓。
- 持仓缓存、分接口限频、账户锁、资金和名额预留、订单意图持久化、撤单终态及部分成交核对。
- 固定追价参考、有限重挂、行情有效性、时段边界；状态不明禁止盲目重试。
- V10在已有退出意图时仍检查公司行动；分红与复权变化不能跳过成本核对。
- Windows调度不依赖Codex打开；电脑关机／睡眠不能成交，恢复仍受数据与窗口约束。

这些是实现与离线故障回归成果，不是长期实盘盈利证明。
