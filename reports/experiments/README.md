# 时间切分消融实验

本目录比较四种 LightGBM 设定：

- `baseline`：原始价量因子，预测未来 5 日原始收益；
- `ranked`：每日横截面排名价量因子，预测未来 5 日收益排名；
- `enhanced`：原始价量因子加 3 个时点可得基本面因子，预测原始收益；
- `ranked_enhanced`：每日横截面排名后的价量与基本面因子，预测收益排名。

## static_2y

- 训练集：2010-01-01 至 2020-12-31
- 验证集：2021-01-01 至 2022-12-31
- 测试集：2023-01-01 至 2024-12-31

这是四个模型的统一静态样本外比较。

## rolling_annual

采用固定长度训练窗口和逐年向前滚动：

- 2010—2020 训练、2021 验证、2022 测试；
- 2011—2021 训练、2022 验证、2023 测试；
- 2012—2022 训练、2023 验证、2024 测试。

每个折先在训练集拟合并用验证集早停，再按选出的最佳迭代轮数在训练集与验证集合并数据上重训，最后预测严格晚于二者的测试年。

所有收益结果采用同一套账户式回测：沪深 300 动态股票池、Top 50、每 5 个交易日调仓、仅交易持仓差额，并计入买卖成本。

注意：由于研究过程中已经查看过 2022—2024 年结果，滚动实验应表述为回顾性样本外检验，不能再把这些年份称为完全未触碰的最终测试集。
