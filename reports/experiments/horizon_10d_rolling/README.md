# 10日收益预测实验

本实验保持 `ranked_enhanced` 的15个排名因子、LightGBM参数、Top50分层权重和年度滚动训练方法不变，只把预测标签改为：

```text
future_return_10d = Close[T+10] / Open[T+1] - 1
target_rank_10d = future_return_10d 的每日横截面百分位排名 - 0.5
```

LightGBM实际拟合 `target_rank_10d`；原始 `future_return_10d` 被保留用于IC和经济意义解释。

## 年度滚动训练

- 2010—2020训练、2021验证、2022测试；
- 2011—2021训练、2022验证、2023测试；
- 2012—2022训练、2023验证、2024测试。

训练集和验证集末尾均清除最后10个信号日，防止10日收益标签跨越数据集边界。每折先使用验证集早停，再按最佳迭代轮数合并训练集和验证集重训。

## 回测方案

同一批10日模型预测分别采用：

- 每5个交易日调仓；
- 每10个交易日调仓。

两者均持有Top50，每次最多替换5只；Top10合计目标权重40%，第11—50名合计60%，并计入相同交易成本。

10日调仓与10日预测区间严格匹配；5日调仓用于检验在预测区间重叠时，更快更新信号是否有额外价值。

本实验是在已经查看过2022—2024表现后增加的周期研究，因此结果属于回顾性稳健性实验，不能再称为完全未触碰的最终样本外检验。
